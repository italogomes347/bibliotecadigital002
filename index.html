    Prompt do CSS

    Crie o CSS completo para uma página escolar de biblioteca digital chamada “Cantinho da Leitura”. Use um visual acolhedor, simples e organizado, com fundo claro em tom de papel, cores terrosas e verdes, títulos elegantes, cartões de livros com capa, título, autor, gênero, resumo expansível e botão de favorito. Estilize também o cabeçalho com a marca e os botões para trocar entre três temas visuais distintos: Clássico, Contemporâneo e Noturno. Inclua estilos para busca, filtro por gênero, ordenação alfabética, contador de livros pela letra inicial e formulário para cadastrar livro com resumo, URL do livro e URL da capa. Faça o layout responsivo para celular e computador, com boa legibilidade, foco visível para teclado e respeito à preferência por movimento reduzido. Não altere a estrutura HTML nem a funcionalidade JavaScript; use as classes e IDs já existentes. Mantenha os textos da página em português brasileiro e cite a IA utilizada no rodapé.
